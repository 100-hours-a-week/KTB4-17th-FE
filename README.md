# *23# 모바일 웹 V1

Figma의 모바일 디자인을 바탕으로 만든 React + Vite 프론트엔드입니다. 기준 화면은 390 × 844px이고, 데스크톱에서는 같은 너비의 모바일 화면을 가운데에 표시합니다.

## 실행

```bash
cd dating-frontend
npm install
npm run dev
```

기본값은 **로컬 데모 모드**입니다. 카카오 로그인 버튼을 누르면 실제 카카오 계정 연결 없이 온보딩을 시작합니다. 온보딩 이후의 추천, 좋아요, 채팅, AI 대화, 알림은 브라우저 `localStorage`에 저장되는 예시 데이터로 동작합니다. 서버 없이 V1의 화면과 이동 흐름을 확인할 수 있습니다.

배포용 번들을 확인하려면 `npm run build`를 실행하세요.

## 포함된 화면

| 영역 | 화면과 동작 |
| --- | --- |
| 로그인·온보딩 | 카카오 로그인 진입, 필수 약관, 기본 정보, 지역 검색, 프로필, 라이프스타일, 가치관 문답 10개, 대표 사진 |
| 홈 추천 | 추천 카드, 프로필 상세, 패스, 좋아요, AI 기능 진입 |
| 좋아요 | 받은·보낸 좋아요, 상호 좋아요 시 채팅방 생성 |
| 채팅 | 목록, 사람과 사람의 메시지 화면, 메시지 입력 |
| AI | 상대와 나의 AI 시뮬레이션, 결과 리포트, 상대 AI와 연습 대화 |
| 마이·알림 | 프로필 수정, 내 페르소나, 선호 설정, 알림 필터·읽음·삭제 |

V1 범위에서 제외된 **AI 채팅 종료 위임, 관상, 사주, 데이터 관리**는 구현하지 않았습니다.

## 백엔드 연결 현황

`.env.example`을 `.env.local`로 복사하고 `VITE_DEMO_MODE=false`로 설정하면 API 모드를 사용할 수 있습니다. `/api`와 `/ws`는 `VITE_API_PROXY_TARGET`으로 프록시됩니다. API 요청에는 쿠키를 포함하고, 변경 요청에는 `XSRF-TOKEN` 쿠키가 있을 때 `X-XSRF-TOKEN` 헤더를 전송합니다.

현재 백엔드 코드에 맞춰 연결한 부분은 카카오 OAuth 시작, 온보딩 상태 조회, 지역 검색, 닉네임 중복 확인, 프로필 저장, 좋아요 발송입니다. 나머지 V1 API의 호출 형식은 `src/api.js`에 모아 두었지만, 백엔드 컨트롤러가 아직 없는 화면은 데모 데이터로 표시됩니다. 특히 본인 정보 저장, 사진 검증·업로드, 가치관 답변, 추천 조회, 받은 좋아요 응답, 사람 채팅, AI 실행과 알림은 백엔드 구현 및 계약 확정 후 실제 데이터로 교체해야 합니다. API 모드는 현재 종단 간 가입이 가능한 상태가 아닙니다.

## 구조

- `src/App.jsx`: V1 화면, 이동, 데모 상호작용
- `src/styles.css`: 모바일 레이아웃과 Pocket Signal 디자인
- `src/data.js`: 선택지와 예시 데이터
- `src/api.js`: 백엔드 요청 및 데모 모드 전환
- `public/assets`: Figma에서 추출한 로고, 일러스트, 화면 아이콘
